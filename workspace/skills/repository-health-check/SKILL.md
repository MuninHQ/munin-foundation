# Repository Health Check

Inspect: branch/status, README and agent instructions, architecture and roadmap alignment, dependency health, tests and CI, secret exposure risks, stale or contradictory docs, changelog/release state, and uncommitted work.

Return findings grouped as critical, important, and improvement. For each finding include evidence, impact, and smallest safe remediation. Do not edit files unless explicitly asked.
