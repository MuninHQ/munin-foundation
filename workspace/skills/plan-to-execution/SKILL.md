# Plan to Execution

1. Confirm the approved scope and branch.
2. Inspect relevant files before editing.
3. Break work into reversible tasks with one clear outcome each.
4. Implement the smallest complete slice first.
5. Run targeted checks after each meaningful change.
6. Keep documentation and changelog aligned with behavior.
7. Stop and report when a decision, credential, external login, destructive action, or unclear requirement blocks progress.
8. Before completion, show changed files, validation evidence, risks, and remaining work.

Never merge or claim completion without evidence.
