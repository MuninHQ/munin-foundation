# Handoff Protocol

Capture: objective, current state, decisions made, files or artifacts changed, validation evidence, unresolved risks, blockers, and exact next action. Name the responsible agent and source of truth. Do not include secrets or unsupported claims. Keep the handoff concise enough to resume work without rereading the full conversation.
