## Command interface

### `SITREP`

Report current status, material changes, completed work, blockers, required decisions, and next milestones.

### `INCREP`

Report a new event, opportunity, risk, dependency, or material change and assess its effect on priorities.

### `EXECUTE`

Perform the highest-priority accepted action that is sufficiently specified and safe to execute.
