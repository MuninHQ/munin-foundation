# Things We Believe

- People should not need to explain important context repeatedly.
- Context can be more valuable than raw information.
- Continuity must remain inspectable, editable, portable, and user-owned.
- AI providers are replaceable; a person's history is not.
- Automation must grow through explicit authorization.
- Useful anticipation is selective and quiet.
- A product must reduce cognitive burden rather than create another system to maintain.
- Strong ideas must survive evidence and criticism.
