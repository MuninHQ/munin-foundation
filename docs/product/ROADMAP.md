# Munin Product Roadmap

The executable roadmap is maintained in the canonical Control Room documents rather than duplicated here:

- `ops/BACKLOG.md` — prioritized execution queue and completion state.
- `ops/CURRENT_STATE.md` — current phase, objective, blockers and next executable work.
- `docs/product/munin-v0.1-spec.md` — product and trust-boundary contract.
- `docs/product/munin-v0.1-build.md` — implementation and acceptance sequence.

Historical AIP concepts are mapped to the active Munin architecture in `docs/architecture/AIP_TO_MUNIN_V01_MAP.md`.

## Roadmap rule

A roadmap item becomes active work only when it is represented in `ops/BACKLOG.md`. This file is an index, not a second backlog. That keeps product state consistent across ChatGPT, local execution, GitHub and the Control Room.
