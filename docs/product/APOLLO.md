# Project Apollo

## Objective

Prove, refine, or reject the Munin thesis before significant implementation.

## Thesis

A user-owned continuity layer that maintains relevant personal context across time and tools can reduce cognitive load and improve decision quality.

## Workstreams

1. Competitive and category research
2. Problem interviews
3. Concierge experiments
4. Thin prototypes
5. Privacy and trust validation
6. Weekly Red Team

## Decision gates

- Is the problem frequent and meaningful?
- Are users already spending effort to solve it?
- Does structured continuity outperform chat history and notes?
- Can value appear without excessive data access?
- Is ongoing maintenance lower than recurring benefit?
- Can the system earn justified trust?

## Kill criteria

Change direction when evidence shows that the problem is infrequent, existing tools are sufficient, value requires disproportionate surveillance, or the category differs only in language rather than behavior.
