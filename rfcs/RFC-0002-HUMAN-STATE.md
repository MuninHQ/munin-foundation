# RFC-0002 — Human State Hypothesis

- **Status:** Draft
- **Created:** 2026-07-13

## Summary

Human State is a research hypothesis: a system can maintain a useful, time-aware, evidence-linked, and user-controlled representation of context currently relevant to a person's life.

## Distinction

Stored memory is not automatically current state. An assertion may be historical, current, planned, inferred, disputed, or expired.

## Candidate dimensions

- Identity
- Relationships
- Missions
- Goals
- Projects
- Resources
- Preferences
- Knowledge
- Experiences
- Commitments
- Current context
- Timeline

## Required properties

Explainable, editable, portable, revocable, consent-scoped, uncertainty-aware, and time-aware.

## Risks

False state, stale assumptions, sensitive inference, surveillance, overconfidence, dependency, manipulation, and lock-in.

## Validation

Compare narrow cross-domain workflows using Human State against ordinary chat history and manually maintained notes.
