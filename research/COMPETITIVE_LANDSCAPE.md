# Competitive Landscape Framework

Evaluate:

- primary job to be done;
- memory model;
- continuity;
- user control;
- portability;
- integrations;
- proactivity;
- explainability;
- provider independence;
- privacy model;
- business model;
- switching cost;
- observed limitations.

Research categories:

- general AI assistants;
- device-native assistants;
- memory and activity capture;
- personal knowledge management;
- productivity workspaces;
- personal CRM;
- agent platforms;
- personal data stores;
- quantified-self systems.

Use primary, dated sources. Separate announcements from generally available behavior.
