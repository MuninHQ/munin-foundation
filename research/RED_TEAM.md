# Red Team

Attack the thesis before reality does.

## Core attacks

1. Munin is only a notes application with AI.
2. General AI providers can reproduce it through memory.
3. Platform owners control the required integrations.
4. Users find persistent context invasive.
5. Maintaining state creates more work than it saves.
6. Incorrect inferences cause harm.
7. The category differs only in language.
8. Useful value requires excessive personal data.
9. The initial market will not pay.
10. Existing tools solve the problem well enough.

## Weekly record

- strongest objection;
- evidence supporting it;
- evidence against it;
- consequence if true;
- test required;
- decision.
