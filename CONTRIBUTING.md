# Contributing

## Rules

- Distinguish evidence, inference, hypothesis, and decision.
- Prefer primary and dated sources.
- Never commit credentials or sensitive personal information.
- Use RFCs for durable proposals.
- Use ADRs for accepted technical or product decisions.
- Keep pull requests small and reviewable.

## Branches

- `research/short-description`
- `rfc/short-description`
- `docs/short-description`
- `experiment/short-description`
- `chore/short-description`
