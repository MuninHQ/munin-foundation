# Canonical Brand Masters

Only owner-approved master artwork belongs in this directory.

Expected files after approval:

- `aj-master.svg`
- `aj-master.png` (transparent, high resolution)
- `munin-raven-seal.svg`
- `munin-raven-seal.png` (transparent, high resolution)

Do not generate these files with an image model. Do not trace screenshots or reconstruct the geometry from prompts. Until an approved master is supplied, keep the corresponding registry entry in `awaiting-master-file` state.

## Approved masters

- `munin-raven-seal.svg` / `.png` and `munin-raven-icon.svg` / `.png`: approved by the owner on 2026-10-15. The owner explicitly authorized an exception to the rule above: the concept was generated with an image model and then redrawn as a vector (exact ring geometry, mirrored markers, bronze eye, traced raven). The provenance is recorded in `registry.json`.
