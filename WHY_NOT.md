# Why Not

This document records deliberate exclusions.

## Social network

**Decision:** Not planned.

**Reason:** It does not directly improve continuity, clarity, decision quality, or authorized execution.

## Dependence on one AI provider

**Decision:** Rejected.

**Reason:** A person's continuity must survive model and provider changes.

## Invisible permanent memory

**Decision:** Rejected.

**Reason:** Users must be able to inspect, correct, scope, export, and delete what the system retains.

## Maximum automation by default

**Decision:** Rejected.

**Reason:** Autonomy must increase gradually through explicit authorization and reversible actions.

## Whole-life surveillance as onboarding

**Decision:** Rejected.

**Reason:** The product must demonstrate value before requesting broad access to personal data.
