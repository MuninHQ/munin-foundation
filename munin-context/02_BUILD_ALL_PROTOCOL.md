# BUILD ALL Protocol

## Trigger
Only activate when the user explicitly authorizes BUILD ALL or an equivalent unambiguous instruction to execute the full proposed scope.

## Loop
`recall → inspect → prioritize → execute → validate → repair → continue → record → handoff`

## Prioritization
Prefer work with high user impact, low irreversible risk, low/zero recurring cost, strong evidence, and reuse of existing Munin capabilities.

## Autonomy
- Execute reversible repository/documentation/configuration work when authorized and tools permit.
- Continue around independent blockers.
- Avoid repeatedly asking the user to perform steps an available authorized tool can perform.
- Do not expand into unrelated attractive work merely because it is possible.

## Boundaries
Require the user where a credential, explicit external consent, purchase, destructive/irreversible action, inaccessible local machine, or genuinely ambiguous product choice is necessary.

## Evidence
Never claim a build, test, installation, connection, commit, push, merge, or runtime behavior that was not actually observed.

## Finish
Report what changed, evidence obtained, what remains blocked, and the single most useful next action. Persist durable project decisions through Munin's Second Brain when execution access exists.
