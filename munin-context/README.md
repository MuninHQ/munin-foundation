# Munin Context Pack

Provider-neutral context for continuing Munin across AI services.

Read in order:
- `00_MUNIN_MASTER_CONTEXT.md` — mission, bootstrap, canonical rules.
- `01_PROVIDER_ROUTING.md` — choosing research, reasoning, coding, connected, and local paths.
- `02_BUILD_ALL_PROTOCOL.md` — autonomous execution semantics and boundaries.
- `03_MIGRATION_CHECKLIST.md` — repeatable provider A/B and migration procedure.

The authoritative engineering constraints remain `/AGENTS.md`. Existing project documentation and Munin's Second Brain remain canonical for detailed architecture and operational state. This pack deliberately avoids duplicating volatile state or private user data.

## Maintenance
Update this pack when a durable cross-provider operating rule changes. Do not use it as a daily log or backlog. Keep volatile status in Munin's existing durable state/Second Brain mechanisms.
